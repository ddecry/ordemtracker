# Guia de contribuição

Obrigado pelo interesse em ajudar o Ordem Tracker! Correções de bugs, novas métricas, melhorias de layout e sugestões são todas bem-vindas.

## Antes de começar

- Para mudanças grandes, abra uma issue primeiro descrevendo a ideia. Assim conseguimos alinhar a proposta antes de você investir tempo nela.
- Para correções pequenas, pode abrir o pull request direto.

## Passo a passo

1. Faça um fork do repositório e crie uma branch com um nome descritivo, como `corrige-grafico-mobile`.
2. Rode o projeto localmente seguindo as instruções do [README](README.md).
3. Faça as alterações e teste no navegador, tanto no tema claro quanto no escuro e também no celular.
4. Abra o pull request explicando o que mudou e por quê. Se a mudança for visual, inclua um print.

## Padrões do projeto

- O projeto não usa frameworks nem dependências no servidor. Converse antes de propor qualquer biblioteca nova.
- Mantenha o estilo do código existente: nomes em português, funções curtas e poucos comentários.
- Sempre que existir, use a API oficial da plataforma.

## Regras importantes

- **Nunca** inclua chaves, senhas ou o arquivo `.env` em commits. Use o `.env.exemplo` como referência.
- Não use imagens, artes ou logos geradas por IA. Utilize apenas imagens públicas e indique a fonte.
- Não altere as logos e artes originais.

## Conduta

Seja respeitoso com todas as pessoas. Críticas devem ser sobre o código, nunca sobre quem o escreveu.
