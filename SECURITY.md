# Política de segurança

Se você encontrou uma vulnerabilidade, **não abra uma issue pública**.

Envie os detalhes para **arthurholanda.virtual@gmail.com**, incluindo:

- uma descrição do problema;
- os passos para reproduzi-lo;
- o impacto que ele pode causar.

Você receberá uma resposta assim que possível. Depois que a correção for publicada, a falha poderá ser divulgada.
